BACKEND API ENDPOINTS (NEW):
───────────────────────────────────────────────────────────────────────────────

✅ GET /api/cities
   Returns: List of all cities in Oman
   Used by: Step 2 - City selection

✅ GET /api/facilities?city_id=XX&types=mosque,hospital
   Returns: Verified facilities filtered by city and type
   Used by: Step 3 - Facility selection

✅ POST /api/donations
   Enhanced to support facility_id parameter
   Creates project automatically if needed
   Sets delivery_status = "received"
   Returns: {id, receipt_number, status}
   Used by: Step 4 - Donation submission

✅ GET /api/donations/{donation_id}
   Returns: Full donation details with project and facility info
   Used by: Step 5 - Tracking display

✅ PUT /api/donations/{donation_id}/track
   Updates delivery status
   Valid statuses: received, preparing, on_the_way, delivered
   Used by: Admin to update delivery status
